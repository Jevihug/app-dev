# My Favorite Series: Avatar: The Last Airbender

**Avatar: The Last Airbender** is an *animated fantasy series* about a world split into four nations, each tied to an element.

## Why I Love It

- Great characters and growth
- A story that mixes humor and heart
- Beautiful world-building

## Main Characters

1. Aang
2. Katara
3. Sokka
4. Toph
5. Zuko

> A show that proves cartoons can tell serious stories too.
